# Code Block Beautify（思源笔记代码块美化）

一款让思源笔记的代码块更漂亮、更好用的插件：**圆角边框、背景美化、长代码折叠、顶部主题装饰栏、代码统计角标、语法高亮主题**，全部功能均可在设置面板中自定义。

## 功能特性

### 🎨 视觉美化
- **圆角 / 边框 / 阴影**：圆角可调、边框宽度与颜色自定义、阴影支持正负值（正数 = 上凸浮起，负数 = 下凹内嵌）
- **边框样式**：实线、虚线、毛玻璃（半透明模糊边框 + 磨砂质感）

### 🖼 背景美化
- **背景颜色 / 背景图片**：自定义背景色；支持本地图片上传、自动虚化、可调遮罩透明度，不影响代码阅读
- **背景主题**：网格纸、点阵、横线本、竖线本、交叉网格、虚线网格、斜纹、笔记本页、碳纤维、小方格纸等 10 种 CSS 纹理

### ⌨ 代码
- **代码统计角标**：代码块底部显示行数 / 字符数（打开即统计，编辑完成后自动刷新）
- **代码字体**：支持常见等宽字体（Consolas / Cascadia Code / JetBrains Mono / Fira Code），默认跟随主题

### 📜 长代码折叠
- 超过设定行数自动显示「收起」按钮，收起后仅显示前 N 行（精确到设置的行数）
- 收起后自动滚动到代码块第一行居中，直接看到折叠效果
- 滚动预览、折叠状态持久化、收起时按钮虚化
- **编辑代码块后自动刷新**（统计与折叠按钮即时更新，无需重启）

### 🗂 顶部主题装饰栏
- Mac（红黄绿圆点）/ Windows（窗口按钮）/ Ubuntu（橙黄绿圆点）/ Chrome（标签页）/ 终端提示符 / 代码符号 六种风格
- **默认主题（daylight / midnight）下自动隐藏装饰栏**，避免与思源原生语言标记（左上角）重叠；**对 Asri 等自定义主题兼容性更好**——语言标记在右侧时不重叠，装饰栏正常显示
- 兼容思源原生右上角工具（语言标签 / 复制 / 更多）

### ✨ 语法高亮主题
- 内置 12 种 highlight.js 主题，可覆盖思源默认

## 安装

### 方式一：思源市场（推荐）
思源笔记 → 设置 → 集市 → 插件 → 搜索「Code Block Beautify」→ 安装。

### 方式二：手动安装
1. 从 [GitHub Releases](https://github.com/dyzlog/SiYuan-code-block-beautify/releases) 下载 `package.zip`
2. 思源笔记 → 设置 → 集市 → 手动安装 → 选择 zip 文件

## 设置说明

设置面板按分组组织，全部设置即时生效、自动保存：

| 分组 | 内容 |
| --- | --- |
| 外观 | 圆角、边框宽度、边框颜色、边框样式、阴影（正/负）、代码字体 |
| 背景 | 背景颜色、背景图片（上传/删除/虚化/遮罩）、背景主题 |
| 代码 | 代码统计角标、长代码折叠（阈值） |
| 语法高亮 | 内置主题选择 |
| 主题风格 | 顶部装饰栏开关与风格 |

> 「恢复默认设置」可一键还原所有参数。

## 主题兼容性

- **Asri 主题**：语言标记显示在代码块右侧，与顶部装饰栏互不遮挡，体验最佳
- **思源默认主题（daylight / midnight）**：原生语言标记位于左上角，插件自动隐藏顶部装饰栏，仅保留长代码折叠按钮，避免重叠

## 数据安全

- 所有装饰元素（统计角标 / 装饰栏 / 折叠按钮）挂在代码块的**兄弟节点**上，**不进入代码块内部**
- 思源保存 / 导出 / 编辑时**不会污染用户代码**
- 关闭文档 / 卸载插件时自动清理全部注入元素
