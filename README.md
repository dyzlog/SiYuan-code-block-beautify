# Code Block Beautify（思源笔记代码块美化）

一款让思源笔记的代码块更漂亮、更好用的插件：**VS Code 风格行号、代码内折叠、缩进竖线、长代码折叠、魔法阵背景、语法高亮主题**，全部功能均可在设置面板中自定义。

## 功能特性

### 🎨 视觉美化
- **圆角 / 边框 / 阴影**：圆角可调、边框颜色自定义、阴影支持正负值（正数 = 上凸浮起，负数 = 下凹内嵌）
- **背景颜色 / 背景图片**：自定义背景色；支持本地图片上传并自动虚化、可调遮罩透明度，不影响代码阅读
- **背景主题**：魔法阵（多层随机生成）、星空、网格纸、点阵、代码雨等多种 CSS 背景

### 🔢 行号
- **VS Code 风格行号**：逐行精确对齐（任何主题/字体下不错位）、右侧分割线
- **当前行高亮**：跟随输入光标，高亮颜色可自定义
- **行号虚拟化**：超长代码只渲染可视区行号，滚动流畅

### 📐 代码内折叠（IDE 式）
- 自动识别 for / if / 函数 / class 等结构，点击折叠箭头收起/展开
- 支持多区域折叠、嵌套折叠自动展开

### 📏 缩进竖线（indent guides）
- VS Code 风格缩进参考线，**彩虹模式**（不同层级不同颜色）或自定义颜色

### 📃 长代码折叠
- 超过设定行数自动显示「收起」按钮，收起后仅显示前 N 行
- 滚动预览、折叠状态持久化、顶部主题装饰栏

### ✨ 顶部主题装饰栏
- Mac（红黄绿圆点）/ Windows（窗口按钮）/ Ubuntu（橙黄绿圆点）/ Chrome（标签页）四种风格

### 🪄 魔法阵背景主题
- 多层随机生成（图层池 12+ 层：同心圆、芒星、星座、北欧符文、行星符号、炼金符号、塔罗圣器等）
- 卫星阵（中心主阵 + 3 小阵环绕）、粒子特效、Canvas 光带
- 明暗主题自动适配线条颜色

### 🌈 语法高亮主题
- 内置 12 款 highlight.js 主题，可覆盖思源默认

## 安装

### 方式一：思源市场（推荐）
思源笔记 → 设置 → 集市 → 插件 → 搜索「Code Block Beautify」→ 安装。

### 方式二：手动安装
1. 从 [GitHub Releases](https://github.com/dyzlog/SiYuan-code-block-beautify/releases) 下载 `package.zip`
2. 思源笔记 → 设置 → 集市 → 手动安装 → 选择 zip 文件

## 设置说明

设置面板按分组组织，全部设置即时生效、自动保存：

| 分组 | 内容 |
| --- | --- |
| 外观 | 圆角、边框、阴影（正/负）、代码字体 |
| 背景 | 背景颜色、背景图片（上传/删除）、虚化、遮罩、背景主题、卫星阵 |
| 代码 | 行号、当前行高亮（颜色）、代码内折叠、长代码折叠（阈值） |
| 缩进竖线 | 开关、彩虹模式、颜色 |
| 语法高亮 | 内置主题选择 |
| 主题风格 | 顶部装饰栏开关与风格 |

> 「恢复默认设置」可一键还原所有参数。
