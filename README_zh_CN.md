# Code Block Beautify（思源笔记代码块美化）

一款让思源笔记的代码块更漂亮、更好用的插件：**圆角边框、背景美化（含便利贴主题）、长代码折叠、顶部主题装饰栏、代码统计角标、语法高亮主题**，全部功能均可在设置面板中自定义，即时生效、自动保存。

## 功能特性

### 🎨 视觉美化
- **圆角 / 边框 / 阴影**：圆角可调、边框宽度与颜色自定义、阴影支持正负值（正数 = 上凸浮起，负数 = 下凹内嵌）
- **边框样式**：实线、虚线、毛玻璃（半透明模糊边框 + 磨砂质感）

### 🖼 背景美化
- **背景颜色 / 背景图片**：自定义背景色；支持本地图片上传、自动虚化、可调遮罩透明度，不影响代码阅读
- **背景主题**：网格纸、点阵、横线本、竖线本、交叉网格、虚线网格、斜纹、笔记本页、碳纤维、小方格纸、**便利贴（柠檬黄折角）** 等 11 种 CSS 纹理

### ⌨ 代码
- **代码统计角标**：代码块底部显示行数 / 字符数（打开即统计，编辑完成后自动刷新）
- **代码字体**：支持常见等宽字体（Consolas / Cascadia Code / JetBrains Mono / Fira Code 等），默认跟随主题

### 📜 长代码折叠
- 超过设定行数自动显示「收起 / 展开」按钮，收起后仅显示前 N 行（精确到设置的行数）
- **折叠状态跨会话持久化**：重开思源 / 重开文档后保持上次的折叠状态
- **按钮隐藏开关**：按钮默认隐藏，鼠标移到按钮位置时显示
- 收起后自动滚动到代码块第一行居中；滚动预览、收起时按钮虚化
- **编辑代码块后自动刷新**（统计与折叠按钮即时更新，无需重启）

### 📐 折叠态滚动条
- 折叠后滚动条默认隐藏，滚动中 / 鼠标移到边缘时显示，不占用空间
- 滚动条显隐不影响布局，滚动到底部不会出现闪烁或"隐藏不了"的问题

### 🗂 顶部主题装饰栏
- Mac（红黄绿圆点）/ Windows（窗口按钮）/ Ubuntu（橙黄绿圆点）/ Chrome（标签页）/ 终端提示符 / 代码符号 六种风格
- **强制兼容主题模式**：语言标记移至右侧与复制/更多并排（仿 Asri 布局），装饰栏在所有主题下均显示，无需担心重叠
- **隐藏头部工具**：一键隐藏语言标记 / 复制 / 更多按钮
- 默认主题（daylight / midnight）下自动隐藏装饰栏，避免与思源原生语言标记重叠；对 Asri 等自定义主题兼容性更好

### ✨ 语法高亮主题
- 内置 12 种 highlight.js 主题，可覆盖思源默认

## 安装

### 方式一：思源市场（推荐）
思源笔记 → 设置 → 集市 → 插件 → 搜索「Code Block Beautify」→ 安装。

### 方式二：手动安装
1. 从 [GitHub Releases](https://github.com/dyzlog/SiYuan-code-block-beautify/releases) 下载 `package.zip`
2. 思源笔记 → 设置 → 集市 → 手动安装 → 选择 zip 文件

## 设置说明

设置面板按分组组织，全部设置即时生效、自动保存：

| 分组 | 内容 |
| --- | --- |
| 外观 | 圆角、边框宽度、边框颜色、边框样式、阴影（正/负）、代码字体 |
| 背景 | 背景颜色、背景图片（上传/删除/虚化/遮罩）、背景主题（含便利贴） |
| 代码 | 代码统计角标、长代码折叠（阈值） |
| 语法高亮 | 内置主题选择 |
| 主题风格 | 装饰栏开关与风格、强制兼容主题、隐藏头部工具、隐藏按钮 |

> 「恢复默认设置」可一键还原所有参数。

## 主题兼容性

- **强制兼容主题模式**：无论使用什么主题，语言标记都会移到右侧与复制/更多并排，装饰栏始终显示——最省心的选择
- **默认模式**：默认主题（daylight / midnight）自动隐藏装饰栏避免重叠；自定义主题（如 Asri）正常显示

## 数据安全

- 所有装饰元素（统计角标 / 装饰栏 / 折叠按钮）挂在代码块的 **overlay 容器**上，overlay 挂在 **.protyle-content 滚动容器下（文档内容结构之外）**，不进入代码块内部
- 思源保存 / 导出 / 编辑时**不会污染用户代码**（实测验证：overlay 不参与文档序列化，装饰不会被写进笔记）
- 关闭文档 / 卸载插件时自动清理全部注入元素
