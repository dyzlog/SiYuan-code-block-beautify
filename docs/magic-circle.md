# 魔法阵背景主题 — 配置文档

> 代码块美化插件（code-block-beautify）的「魔法阵」背景主题参数与图层池说明。

## 参数配置表

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 数量 | 每 **20 行** 1 个（至少 1 个） | 40 行 → 2 个，60 行 → 3 个 |
| 大小 | **350 ~ 700px** | 随机 |
| 位置 | 代码块内随机分布 | `left 12~80%`、`top 8~83%`，避开左侧行号列 |
| 图层嵌套层数 | **3 ~ 6 层** | 从 10 层池中保持「外 → 内」顺序随机选取 |
| 颜色 | 每个魔法阵**独立随机色** | `hsl(随机色相 80% 55%)` |
| 粒子特效 | **70% 概率**随机附加 | 8 ~ 20 个光点，随机位置 / 大小 / 颜色 / 动画 |
| 存在时间 | **3 分钟** | 到点消失 → 重新随机生成 |
| 稳定性 | 滚动 / 重扫**不更新** | 仅元素丢失时补齐，关闭主题才清理 |

## 附加：粒子特效

不属于图层池，随机附加到整个魔法阵（约 70% 概率）：

- 8 ~ 20 个圆形光点，2 ~ 5px，随机亮色（HSL 高饱和高亮度）
- 动画：漂浮（位移 8px / -10px）+ 闪烁（透明度 0.15 ↔ 0.9）+ 缩放（0.7 ↔ 1.3）
- 每个粒子随机延迟与时长（3 ~ 7s），互不同步
